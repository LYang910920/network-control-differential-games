\section{The modeling question and the learning route}
A network intervention changes a process that is already evolving: infected devices recover, vulnerable devices are patched, competing messages spread, or a campaign produces an immediate change in awareness. A useful control model connects four objects: the state, the intervention mechanism, the information available to the decision maker, and the objective. This note follows that connection from a graph to differential equations, from equations to optimality conditions, and from conditions to executable examples.

The first example allocates recovery effort among degree classes. The same construction then extends to individual nodes, two strategic players, and interventions that cause jumps. Classical optimal-control results are developed using the minimization convention $H=L+\lambda^\top f$ \cite{pontryagin,liberzon,lenhart}. Payoff-maximizing games are identified explicitly when introduced.


\subsection{Research context: from cyber dynamics to interventions}
The examples in this tutorial grow out of a line of cyber/network modeling and control research by Lu-Xing Yang and collaborators. Security evaluation under advanced persistent threats provides a starting point: derive the evolving attack--defense state, then connect its long-run behavior to a security measure \cite{security2017}. Introducing strategic intervention leads to patch-injection and repair games \cite{patch2018,repair2019}; introducing recoverable data changes the available defense mechanisms and leads to backup-and-recovery decisions \cite{backup2021}. These are distinct modeling questions even when their optimality systems have the same state--costate form.

The social-network branch develops objectives for conflicting opinions and rumor refutation \cite{opinions2020,rumor2021}. Hybrid propaganda competition then combines sustained effort with discrete campaigns \cite{war2024}, while awareness-dependent propaganda suppression and coupled malware--opinion dynamics connect behavior with impulse interventions \cite{awareness2025,malware2025}. Impulsive artificial defense and defense outsourcing provide related APT settings in which event timing and the allocation of decision authority matter \cite{impulse2023,outsource2024}. Finally, feedback-loop malware control links parameter learning with model predictive control (MPC) \cite{feedback2024}.

The compact SIS/SIR equations below are teaching models that isolate those mathematical ingredients. The later research examples explain how to move from them to the cited publications and their code. A tutorial illustration is identified separately from a paper's original model or algorithm; changing the physical state, information pattern or cost creates a different problem.

A state such as $x_i\in[0,1]$ is an infection probability or mean-field fraction, not a binary observation of a particular host. The expected infected population is $\sum_i x_i$. A degree-class state $x_k$ is the infected fraction \emph{within} class $k$, and the population fraction is $\sum_k P(k)x_k$. If time is measured in hours, transmission, natural recovery and recovery-control intensities have units of inverse hours. An impulse fraction is dimensionless; its cost is charged at an event rather than multiplied by the duration of a numerical step.

\subsection{Three model resolutions}
An aggregate compartment model describes a population by a few states, such as $S,I,R$. A degree-level model keeps a separate state for every observed degree. A node-level model keeps a separate state for every node and uses the adjacency matrix directly. These are distinct approximations. An aggregate SIR system does not become degree-level merely by storing its three compartments in an array.

The degree model reduces dimension when the number of observed degrees is much smaller than $n$. The node model retains location, direction and weighted contacts. A degree closure can lose correlations between a node's state and its neighbors; a node mean-field model still approximates stochastic dependencies between individual infection events. Model resolution should therefore follow the scientific question rather than the available array size.

\section{From external network data to model inputs}
\subsection{Read the graph and preserve node identities}
The introductory command accepts a whitespace-separated edge list, a CSV edge list, a numeric adjacency CSV, or a supported NetworkX graph file. For example:
\begin{lstlisting}[language={},caption={CSV edge-list structure}]
source,target,weight
001,002,1.0
002,003,0.5
003,001,1.0
\end{lstlisting}
Identifiers such as \texttt{001} are labels, not numbers to be rounded or renumbered implicitly. The repository reader stores them as text. Repeated edge records are summed, including reversed records of an undirected edge. Self-loops are removed, zero-weight edges create no contact, and negative or nonfinite weights are rejected. An edge list cannot describe a node that appears nowhere in the data; use GraphML, a numeric adjacency matrix, or an explicit node list when isolates matter.

A graph-to-matrix conversion must use a fixed node order. NetworkX stores a directed edge from source $i$ to target $j$ in position $(i,j)$; the incoming-influence convention used here requires its transpose \cite{networkx}:
\begin{lstlisting}[caption={Construct an incoming-influence matrix}]
import networkx as nx
import numpy as np

nodes = list(graph.nodes())
A = nx.to_scipy_sparse_array(
    graph, nodelist=nodes, weight="weight", format="csr"
).T.tocsr()
x = np.full(len(nodes), 0.05)
pressure = A @ x
# Save nodes alongside any node-indexed trajectories.
\end{lstlisting}
For an undirected graph the transpose makes no numerical difference. For a directed graph it determines which nodes receive infection pressure. For example, an edge $j\to i$ must contribute $A_{ij}x_j$ to node $i$.

\subsection{Compute the empirical degree distribution first}
For the full, simple, undirected input graph, compute
\begin{equation}
N_k=\#\{i:\deg(i)=k\},\qquad P(k)=\frac{N_k}{n},\qquad
\bar k=\sum_{k\in\mathcal K}kP(k).
\label{eq:degree-distribution}
\end{equation}
Only observed classes are stored; $k=0$ is included when isolates exist. A compact calculation is
\begin{lstlisting}[caption={Degree classes are columns of the state array}]
degrees = np.fromiter((d for _, d in graph.degree()), dtype=int)
k, N_k = np.unique(degrees, return_counts=True)
p = N_k / N_k.sum()
kbar = float(k @ p)
# X.shape == (number_of_times, len(k))
# X[:, j] is the infected fraction for degree k[j].
\end{lstlisting}
Here degree counts distinct neighbors. Weighted strength, $\sum_j A_{ij}$, is a different quantity. The repository function \texttt{degree\_distribution\_from\_graph} returns these arrays together in a \texttt{DegreeData} object. Degree statistics are computed before any node-level subgraph is selected, and computing them does not require a dense $n\times n$ matrix.

\subsection{Derive the uncorrelated degree closure}
Choose a random edge endpoint in an undirected network. Class $k$ contributes $kN_k$ endpoints, so its endpoint probability is $kP(k)/\bar k$. Under the uncorrelated degree approximation, the probability that a neighbor is infected is
\begin{equation}
\Theta(t)=\sum_{k\in\mathcal K}\frac{kP(k)}{\bar k}x_k(t).
\label{eq:theta}
\end{equation}
Thus a susceptible degree-$k$ node has expected infected-neighbor count $k\Theta$. For an edgeless graph, set $\Theta=0$; the state then evolves through recovery and intervention only. No division by zero is needed.

The closure uses unweighted contacts. Reading and retaining edge weights does not make this particular degree equation weight-aware. Likewise, replacing $k$ by in-degree is not, by itself, a derivation for a directed network. Direction, weight, degree correlation, and neighbor-state correlation require a suitable extension or a node-level model.

\subsection{Retain degree correlations when they matter}
Let $M_{k\ell}$ be the conditional probability that a neighbor of a degree-$k$ node has degree $\ell$. The correlated pressure is
\begin{equation}
\Theta_k(t)=\sum_{\ell\in\mathcal K}M_{k\ell}x_\ell(t).
\end{equation}
For an empirical undirected graph, let $E_{k\ell}$ count oriented edge endpoints from class $k$ to class $\ell$: every undirected edge contributes both orientations. Then
\begin{equation}
M_{k\ell}=\frac{E_{k\ell}}{kN_k}\quad(k>0),\qquad M_{0\ell}=0.
\label{eq:empirical-mixing}
\end{equation}
Non-isolate rows sum to one, and the endpoint counts satisfy
\begin{equation}
kP(k)M_{k\ell}=\ell P(\ell)M_{\ell k}.
\end{equation}
This balance relation is useful when inventing a mixing matrix: an arbitrary row-stochastic matrix need not correspond to an undirected graph with the stated degree distribution. The uncorrelated approximation sets every non-isolate row to $\ell P(\ell)/\bar k$. Empirical mixing preserves degree correlations, but still replaces individual neighbor states by their class means.

\begin{keyidea}{A matrix transformation is a modeling choice}
Row normalization replaces contact counts by normalized influence. Multiplying the whole matrix by a constant changes the transmission scale unless the rate is adjusted accordingly. Selecting a high-degree induced subgraph removes contacts and defines a different dynamical system. State these choices when interpreting a result; none is merely a formatting operation.
\end{keyidea}

\section{Controlled propagation models}
\subsection{Degree-level and node-level SIS dynamics}
The first model uses recovery control:
\begin{equation}
\dot x_k=\beta k(1-x_k)\Theta-(\delta+u_k)x_k,
\qquad 0\le u_k\le\bar u_k.
\label{eq:degree-sis}
\end{equation}
Here $\beta$ is the per-contact transmission rate, $\delta$ is natural recovery, and $u_k$ is extra recovery/removal effort. A corresponding node-level model is
\begin{equation}
\dot x_i=\beta_i(1-x_i)\sum_j A_{ij}x_j-(\delta_i+u_i)x_i.
\label{eq:node-sis}
\end{equation}
All rates and matrix entries are nonnegative. At $x_i=0$, the derivative is nonnegative; at $x_i=1$, it equals $-(\delta_i+u_i)\le0$. Therefore the vector field points inward on the boundary of $[0,1]^n$. The same argument applies to degree classes. This property belongs to the differential equations. Large numerical clipping corrections would indicate a numerical problem rather than establish the property.

Heterogeneity can be represented by class- or node-specific susceptibility, infectivity, recovery, costs and bounds. A useful degree form is
\begin{equation}
\dot x_k=s_k k(1-x_k)\sum_\ell M_{k\ell}b_\ell x_\ell
 -(\delta_k+u_k)x_k.
\label{eq:heterogeneous-degree}
\end{equation}
The acquisition coefficient $s_k$ includes the transmission-rate scale; $b_\ell$ describes relative infectivity. In \texttt{DegreeSISParams}, these correspond to \texttt{susceptibility} and \texttt{infectivity}. Passing $s_k=\beta$ and $b_\ell=1$ recovers \eqref{eq:degree-sis} under uncorrelated mixing.

\subsection{Patching and cleaning are different transitions}
To distinguish protection from recovery, use a controlled SIR/SIPS-type model:
\begin{align}
\dot S&=-\beta SI-u_pS+\omega R,\nonumber\\
\dot I&=\beta SI-(\gamma+u_c)I,\label{eq:patch-clean}\\
\dot R&=u_pS+(\gamma+u_c)I-\omega R.\nonumber
\end{align}
Patching $u_p$ moves $S\to R$, whereas cleaning $u_c$ moves $I\to R$. The sum of the equations is zero. In the SIS example, recovered devices immediately rejoin susceptibility, so its recovery control should not be described as SIR patching. This distinction also determines the Hamiltonian derivative: patching has a marginal state effect proportional to $S$, while cleaning has one proportional to $I$.

\subsection{Objectives, population weights and shared resources}
For degree-level control, use
\begin{equation}
J(u)=\int_0^T\sum_k P(k)\left[q_kx_k+\frac{r_k}{2}u_k^2\right]\dd t
+\Phi(x(T)),\qquad r_k>0.
\label{eq:degree-objective}
\end{equation}
This is a per-capita weighted objective. Multiplying the entire objective by $n$ leaves its minimizer unchanged. Multiplying only the state term by $n$ changes the tradeoff. A node-level objective may instead sum host-specific risks and intervention costs, or divide the entire sum by $n$; make that choice consistently in the solver and every baseline.

Independent bounds model separate capacity limits. A shared budget, such as
\begin{equation}
\sum_k c_k u_k(t)\le B(t),\qquad c_k>0,
\end{equation}
couples the decisions. The meaning of $c_k$ must specify whether effort is charged per class, per node, or by class population. Independent clipping generally does not enforce this budget.

\subsection{An optional connection to a propagation threshold}
For a fixed control $u$ and node dynamics $\dot x=(I-\diag x)Bx-Dx$, define
$B_{ij}=\beta_i A_{ij}$ and $D=\diag(\delta_i+u_i)$, with all diagonal entries of $D$ positive. Linearization at zero is $\dot z=(B-D)z$.
\begin{proposition}[A sufficient extinction condition]
If $\rho(D^{-1}B)<1$, the disease-free state is globally exponentially stable on $[0,1]^n$.
\end{proposition}
\begin{proof}
The matrix $B-D$ is Metzler and Hurwitz under the stated spectral condition. Since $\dot x\le(B-D)x$ componentwise, comparison with the positive linear system gives $0\le x(t)\le e^{(B-D)t}x(0)$, which decays exponentially.
\end{proof}
For the homogeneous, uncontrolled degree closure, the rank-one next-generation matrix gives
\begin{equation}
\mathcal R_0=\frac{\beta\sum_k k^2P(k)}{\delta\bar k}.
\end{equation}
This explains why the second degree moment can matter even at the same average degree. The strict threshold concerns long-run persistence under fixed coefficients. Finite-horizon control also depends on current infections, the remaining time and costs; a spectral ranking and an optimal finite-horizon allocation need not agree. The equality case is not classified by the strict comparison argument above.

\section{Pontryagin's principle: derivation and interpretation}
\subsection{The continuous-time problem}
Consider
\begin{equation}
\min_{u(\cdot)}J(u)=\Phi(x(T))+\int_0^T L(x,u,t)\dd t,
\qquad \dot x=f(x,u,t),\quad x(0)=x_0,\quad u(t)\in U.
\label{eq:generic-control}
\end{equation}
Assume a fixed horizon, a fixed initial state, a free terminal state, suitable smoothness in $x$, and admissible measurable controls for which solutions exist. The presentation treats the normal case and no additional active state-path constraints. Endpoint constraints, state constraints and abnormal extremals require their corresponding multipliers and transversality conditions \cite{pontryagin,liberzon}.

Define
\begin{equation}
H(x,u,\lambda,t)=L(x,u,t)+\lambda^\top f(x,u,t).
\end{equation}
Introduce a multiplier for the differential equation:
\begin{equation}
\mathcal A=\Phi(x(T))+\int_0^T\left[H(x,u,\lambda,t)-\lambda^\top\dot x\right]\dd t.
\end{equation}
For a state variation $z$ with $z(0)=0$, integration by parts gives
\begin{align}
\delta\mathcal A
={}&[\Phi_x(x(T))-\lambda(T)]^\top z(T)\nonumber\\
&+\int_0^T(H_x+\dot\lambda)^\top z\dd t
+\int_0^T H_u^\top\delta u\dd t.
\label{eq:pmp-variation}
\end{align}
Choosing the costate to cancel state variations yields the adjoint and terminal equations. Needle variations supply the pointwise Hamiltonian minimum condition; an ordinary differentiable variation supplies its first-order form on a convex control set.

\begin{theorem}[Normal PMP conditions]
An optimal pair in the stated setting has a costate satisfying, almost everywhere,
\begin{align}
\dot x^*&=f(x^*,u^*,t),\qquad x^*(0)=x_0,\nonumber\\
\dot\lambda^*&=-H_x(x^*,u^*,\lambda^*,t),\qquad
\lambda^*(T)=\Phi_x(x^*(T)),\label{eq:pmp-system}\\
u^*(t)&\in\argmin_{v\in U}H(x^*(t),v,\lambda^*(t),t).\nonumber
\end{align}
These are necessary conditions. The state equation runs forward from $0$; the costate equation runs backward from $T$.
\end{theorem}

A costate measures first-order sensitivity of future cost along an extremal. Identifying it with the gradient of a value function requires the differentiability and optimality assumptions of the value-function formulation; it is not an automatic interpretation of every numerically generated adjoint.

\subsection{Bounds and projected optimality}
For a differentiable Hamiltonian and a convex control set, its first-order necessary condition is
\begin{equation}
H_u(u^*)^\top(v-u^*)\ge0\qquad\text{for all }v\in U.
\label{eq:control-vi}
\end{equation}
For a scalar interval $[0,\bar u]$, this reads
\begin{equation}
H_u=0\text{ in the interior},\qquad H_u\ge0\text{ at }u=0,
\qquad H_u\le0\text{ at }u=\bar u.
\end{equation}
Thus penalizing $H_u^2$ at every time would penalize some correct boundary solutions. For any $\eta>0$, the equivalent projected first-order residual is
\begin{equation}
r_u=u-\proj_U(u-\eta H_u).
\label{eq:projected-gradient}
\end{equation}
If $H$ is convex in $u$, a zero residual is sufficient for its pointwise minimum. It still does not establish global optimality of the full nonlinear trajectory problem.

When $H(u)=r u^2/2-bu+\text{constant}$ with $r>0$, its minimizer is
$u^*=\clip(b/r,0,\bar u)$. Taking $\eta=1/r$ in \eqref{eq:projected-gradient} gives exactly $r_u=u-u^*$.

\subsection{When necessary conditions become sufficient}
\begin{theorem}[A convexity sufficiency result]
Suppose a candidate satisfies \eqref{eq:pmp-system}. Suppose $\Phi$ is convex and, for almost every $t$, $H(x,u,\lambda^*(t),t)$ is jointly convex in $(x,u)$ on a convex domain containing all compared admissible pairs. Then the candidate is globally optimal for \eqref{eq:generic-control}.
\end{theorem}
\begin{proof}
For an admissible comparison pair, write $z=x-x^*$. Integration by parts using the costate equation gives
\begin{align*}
J(u)-J(u^*)={}&\Phi(x(T))-\Phi(x^*(T))-\lambda^*(T)^\top z(T)\\
&+\int_0^T\big[H(x,u,\lambda^*,t)-H(x^*,u^*,\lambda^*,t)-H_x^\top z\big]\dd t.
\end{align*}
Terminal convexity makes the first line nonnegative. Joint Hamiltonian convexity bounds the integrand below by $H_u^\top(u-u^*)$, which is nonnegative by \eqref{eq:control-vi}.
\end{proof}

Nonlinear propagation includes products of states and controls. A positive quadratic effort cost makes the Hamiltonian convex in each control, but does not automatically make it jointly convex in states and controls. For these examples, the sweep usually produces a PMP candidate; a separate verification argument would be needed for a global guarantee.

\begin{example}[A transparent sufficient case]
For $\dot x=u$ and
$J=\tfrac12 s x(T)^2+\tfrac12\int_0^T(x^2+r u^2)\dd t$ with $s\ge0,r>0$,
PMP gives $\dot\lambda=-x$, $u=-\lambda/r$, and $\lambda(T)=sx(T)$.
Set $\lambda=P(t)x$. Then
\[
-\dot P=1-P^2/r,\qquad P(T)=s,\qquad u=-P(t)x/r.
\]
The Hamiltonian is jointly convex, so the resulting extremal is optimal. The quadratic value function $V(t,x)=P(t)x^2/2$ also verifies optimality through HJB.
\end{example}

\section{Derive the network-control equations}
\subsection{Degree-class costates and controls}
For \eqref{eq:degree-sis}, set $w_k=kP(k)/\bar k$ when $\bar k>0$ and $w_k=0$ otherwise. The Jacobian entries are
\begin{equation}
\frac{\partial f_k}{\partial x_\ell}
=\beta k(1-x_k)w_\ell
-\mathbf1_{\{k=\ell\}}\big[\beta k\Theta+\delta+u_k\big].
\label{eq:degree-jacobian}
\end{equation}
For $L=\sum_kP(k)[q_kx_k+r_ku_k^2/2]$, the costate equations become
\begin{align}
\dot\lambda_\ell={}&-q_\ell P(\ell)
+\lambda_\ell[\beta\ell\Theta+\delta+u_\ell]\nonumber\\
&-w_\ell\sum_k\lambda_k\beta k(1-x_k),
\qquad \lambda(T)=\Phi_x(x(T)).
\label{eq:degree-adjoint}
\end{align}
The sum over all classes is essential: changing one class changes the pressure experienced by every other class. Since $\partial f_k/\partial u_k=-x_k$,
\begin{equation}
H_{u_k}=r_kP(k)u_k-\lambda_kx_k,
\qquad
u_k^*=\clip\left(\frac{\lambda_kx_k}{r_kP(k)},0,\bar u_k\right).
\label{eq:degree-update}
\end{equation}
All stored observed classes have $P(k)>0$. Isolates have zero infection pressure but can still receive recovery effort if initially infected.

For the heterogeneous model, replace the rank-one transmission matrix by
$B_{k\ell}=s_k kM_{k\ell}b_\ell$. The same matrix formula applies:
\begin{equation}
f=(1-x)\odot(Bx)-(\delta+u)\odot x,
\quad
f_x=\diag(1-x)B-\diag(Bx+\delta+u).
\label{eq:matrix-sis}
\end{equation}
Here $\odot$ denotes componentwise multiplication. This form keeps the model, its Jacobian and its adjoint visibly aligned.

\subsection{Node-level costates and controls}
For \eqref{eq:node-sis}, define $B=\diag(\beta_i)A$ and use the same $f_x$ in \eqref{eq:matrix-sis}. With $L=\sum_i[q_ix_i+r_i u_i^2/2]$,
\begin{equation}
\dot\lambda=-q-f_x^\top\lambda,\qquad
u_i^*=\clip(\lambda_i x_i/r_i,0,\bar u_i).
\end{equation}
For large sparse networks, the adjoint only needs a Jacobian-vector product:
\begin{equation}
f_x^\top\lambda
=B^\top[(1-x)\odot\lambda]-(Bx+\delta+u)\odot\lambda.
\label{eq:jvp}
\end{equation}
No dense Jacobian is needed to evaluate this expression. Sparsity reduces computation without changing the model, unlike replacing the full network by a smaller induced subgraph.

\subsection{A shared budget changes the update}
At a fixed time, suppose the Hamiltonian control terms are
$\sum_k[r_kP(k)u_k^2/2-b_ku_k]$ and $\sum_k c_ku_k\le B$. A nonnegative multiplier $\mu$ gives
\begin{equation}
u_k(\mu)=\clip\left(\frac{b_k-\mu c_k}{r_kP(k)},0,\bar u_k\right).
\end{equation}
If the unconstrained allocation is feasible, take $\mu=0$. Otherwise choose $\mu$ so the budget is tight. The total expenditure is nonincreasing in $\mu$, making a scalar bisection sufficient for this particular convex subproblem. More general coupled constraints require their own constrained Hamiltonian minimization.

\subsection{A different intervention requires a different derivative}
For transmission reduction,
\begin{equation}
f_k=\beta(1-u_k)k(1-x_k)\Theta-\delta x_k,
\qquad 0\le u_k\le1,
\end{equation}
we have $f_{k,u_k}=-\beta k(1-x_k)\Theta$. Therefore
\begin{equation}
u_k^*=\clip\left(
\frac{\lambda_k\beta k(1-x_k)\Theta}{r_kP(k)},0,\bar u_k\right).
\end{equation}
Its state Jacobian also changes. Keeping the old $\lambda_kx_k$ update after replacing the state equation would optimize the wrong intervention mechanism.

\section{Numerical solution and the first executable example}
\subsection{Forward--backward sweep}
Initialize an admissible control on a time grid. With that control held fixed, solve the state equation forward. Interpolate the state and control consistently, solve the costate equation backward, and form the pointwise Hamiltonian minimizer. Let $U$ denote all control values on the grid and $\mathcal T(U)$ their candidate update. Compute
\begin{equation}
\varepsilon=\norm{\mathcal T(U)-U}_\infty.
\end{equation}
Stop when this residual is small. Otherwise relax,
\begin{equation}
U\leftarrow(1-\alpha)U+\alpha\mathcal T(U),\qquad0<\alpha\le1,
\end{equation}
and repeat. A small relaxed step alone is inconclusive when $\alpha$ is small. The returned trajectory and objective must be replayed under the returned control, rather than under the previous iterate.

Forward--backward sweep is a fixed-point method; convergence requires conditions, and is not guaranteed for every nonlinear problem or horizon \cite{mcasey}. Grid refinement, tighter integration tolerances and alternative initial controls help distinguish discretization error from a difficult boundary-value problem. Direct transcription instead optimizes a finite-dimensional state/control parameterization subject to discretized dynamics. It is a useful comparison method, but its nonlinear optimizer may also return a local solution.

\section{Differential games on the same network}
\subsection{Specify the players and the information structure}
An open-loop strategy is a function of time for a specified initial state. A feedback strategy can depend on the currently observed state and time. A Nash profile permits unilateral changes by each player while the others' strategies are fixed. A Stackelberg leader commits first and anticipates a follower's response. These distinctions concern the problem itself, not the order of loops in a numerical solver \cite{basar}.

For two players maximizing payoffs $J_A,J_D$, an open-loop Nash profile satisfies
\begin{equation}
J_A(a^*,d^*)\ge J_A(a,d^*),\qquad
J_D(a^*,d^*)\ge J_D(a^*,d)
\end{equation}
for every admissible unilateral deviation. With cost minimization, reverse the inequalities. Opponent controls are held fixed when deriving an open-loop best-response adjoint. Substituting a state-dependent opponent policy changes those derivatives and does not automatically produce a feedback Nash condition.

\subsection{A degree-class attacker--defender game}
Use
\begin{equation}
\dot x_k=\beta(1+a_k)k(1-x_k)\Theta-(\delta+d_k)x_k,
\end{equation}
where $a_k\in[0,\bar a_k]$ amplifies acquisition in recipient class $k$ and $d_k\in[0,\bar d_k]$ increases recovery. This placement of $a_k$ is part of the model; donor-targeted amplification would have different derivatives. Let
\begin{align}
J_A&=\int_0^T\sum_kP(k)\left[q_Ax_k-\frac{c_A}{2}a_k^2\right]\dd t,\nonumber\\
J_D&=\int_0^T\sum_kP(k)\left[-q_Dx_k-\frac{c_D}{2}d_k^2\right]\dd t.
\label{eq:game-payoffs}
\end{align}
Both players maximize their own payoff; the two payoffs are generally not negatives of each other. Define $H_A=F_A+\lambda_A^\top f$ and $H_D=F_D+\lambda_D^\top f$, where $F_A,F_D$ are the running payoffs. The necessary conditions are one shared state equation and
\begin{equation}
\dot\lambda_A=-q_AP-f_x^\top\lambda_A,\qquad
\dot\lambda_D=q_DP-f_x^\top\lambda_D,
\qquad \lambda_A(T)=\lambda_D(T)=0.
\end{equation}
Here $P$ denotes the vector of class probabilities. Hamiltonian maximization gives
\begin{align}
a_k^*&=\clip\left(\frac{\lambda_{A,k}\beta k(1-x_k)\Theta}{c_AP(k)},0,\bar a_k\right),\nonumber\\
d_k^*&=\clip\left(-\frac{\lambda_{D,k}x_k}{c_DP(k)},0,\bar d_k\right).
\label{eq:game-update}
\end{align}
The sign difference follows from the state effects, not from changing the adjoint convention arbitrarily. Each Hamiltonian is concave in its own scalar effort in this example, but the coupled nonlinear trajectory problem still requires separate equilibrium justification.

The node-level game replaces class pressure by $\sum_jA_{ij}x_j$ and class weights by the chosen node objective weights. Its dimension is the number of nodes, not the number of degree classes. The repository provides both \texttt{solve\_degree\_game} and \texttt{solve\_node\_game}.

\subsection{What a numerical game iteration establishes}
A coupled forward--backward iteration advances the shared state, solves both adjoints and updates both effort schedules. Convergence supplies a solution of the numerical necessary-condition system, not automatically a Nash equilibrium. A meaningful unilateral-response comparison fixes the opponent and searches over the same admissible strategies, dynamics and payoff.

For a payoff-maximizing player, define
\begin{equation}
\Delta_i=\sup_{v_i}J_i(v_i,u_{-i}^*)-J_i(u_i^*,u_{-i}^*).
\end{equation}
A profile is an $\varepsilon$-Nash equilibrium when every $\Delta_i\le\varepsilon$. A finite collection of tested deviations, or an imperfectly optimized learned response, gives a \emph{lower bound} on this supremum. Finding an improvement disproves exact equilibrium; failing to find one does not certify a small global gap.

For a Stackelberg game, the leader optimizes through a follower response mapping. Response multiplicity requires a stated selection rule. Updating the leader first in an ordinary Nash sweep does not implement that commitment problem.

\section{Dynamic programming, HJB and feedback verification}
\subsection{The value function and Bellman's argument}
For the minimization problem, define the optimal remaining cost
\begin{equation}
V(t,x)=\inf_{u(\cdot)}\left\{\int_t^T L(x(s),u(s),s)\dd s+\Phi(x(T))\right\}.
\end{equation}
Over a short first interval, dynamic programming gives
$V(t,x)=\inf_u\{L\,h+V(t+h,x+hf)+o(h)\}$. If $V$ is differentiable, dividing by $h$ yields
\begin{equation}
V_t+\min_{u\in U}\{L(x,u,t)+\nabla_xV^\top f(x,u,t)\}=0,
\qquad V(T,x)=\Phi(x).
\label{eq:hjb}
\end{equation}
A minimizing selector $u^*(t,x)$ is a feedback law defined over a state domain rather than a schedule for one initial state.

\begin{theorem}[Smooth HJB verification]
Suppose $V\in C^1$ satisfies \eqref{eq:hjb}, and a measurable minimizing selector generates admissible trajectories. Then $V$ is the value function and that selector is optimal.
\end{theorem}
\begin{proof}
For every admissible control, $L+V_t+\nabla V^\top f\ge0$. Integrating along its trajectory gives $J(u)\ge V(0,x_0)$. Equality holds along the minimizing selector, proving the claim.
\end{proof}
The value function can be nonsmooth. In that case the classical derivatives used here must be replaced by the appropriate generalized/viscosity formulation; fitting a smooth neural function does not establish classical differentiability of the true value.

Along a sufficiently smooth optimal trajectory, $\lambda(t)=\nabla_xV(t,x^*(t))$ relates dynamic programming to PMP. PMP describes one extremal trajectory; HJB describes values and decisions throughout the state domain. This explains both the interpretability of trajectory methods and the dimensional challenge of feedback PDEs.

\subsection{Zero-sum and general-sum feedback games}
For a zero-sum running payoff $\ell$ maximized by an attacker and minimized by a defender, the formal Isaacs Hamiltonian is
\begin{equation}
\mathcal H(x,p,t)=\max_a\min_d\{\ell(x,a,d,t)+p^\top f(x,a,d,t)\}.
\end{equation}
The opposite order defines the other game value. Equality of the two pointwise orders is the Isaacs condition. A smooth value satisfying $V_t+\mathcal H(x,\nabla V,t)=0$, together with admissible saddle selectors and the requisite game assumptions, supports feedback verification. The order should never be changed without identifying the information and strategy conventions.

For a general-sum payoff-maximizing game, each player has a value $V_i$. A smooth feedback Nash candidate satisfies
\begin{align}
0&=(V_i)_t+F_i(x,u_i^*,u_{-i}^*,t)+\nabla V_i^\top f(x,u_i^*,u_{-i}^*,t),\nonumber\\
u_i^*&\in\argmax_{u_i}\{F_i(x,u_i,u_{-i}^*,t)+\nabla V_i^\top f(x,u_i,u_{-i}^*,t)\}.
\end{align}
These coupled equations retain separate objectives. Minimizing the sum of players' costs generally defines a social-planning problem instead.

\section{Impulses, switches and hybrid control}
\subsection{Describe timing, action values and state effects separately}
A sampled real-valued action becomes piecewise constant under zero-order hold. A discrete mode selects a vector field. Neither causes a state jump unless a reset map is specified. In a continuous--impulsive model,
\begin{align}
\dot x&=f(x,u,t),\qquad t\ne\tau_\ell,\nonumber\\
x(\tau_\ell^+)&=G_\ell(x(\tau_\ell^-),v_\ell,\tau_\ell),\label{eq:reset}\end{align}
and the cost includes $\sum_\ell K_\ell(x(\tau_\ell^-),v_\ell,\tau_\ell)$.
For example, an isolation impulse sends $I^+=(1-v)I^-$ and $R^+=R^-+vI^-$, while leaving $S$ unchanged. A continuous isolation \emph{rate} is a different model.

To simulate a fixed schedule, integrate exactly to the first event, save the left limit, apply the reset, save the right limit and restart the solver. Repeat at every event. Do not interpolate continuously through a jump or apply its cost on every solver substep.

\subsection{Costate jump: derive it from the reset}
Let $x^-=x(\tau^-)$ and $x^+=G(x^-,v,\tau)$. For a fixed event time, a perturbation gives
$\delta x^+=G_x\delta x^-+G_v\delta v$. The first-order event contribution is
\[
K_x^\top\delta x^-+K_v^\top\delta v+(\lambda^+)^\top\delta x^+.
\]
Matching the coefficient of $\delta x^-$ to the pre-event costate yields
\begin{equation}
\boxed{\lambda^-=G_x^\top\lambda^++K_x.}
\label{eq:costate-jump}
\end{equation}
For a differentiable reset and convex impulse set $\mathcal V$, the necessary first-order magnitude condition is
\begin{equation}
\big(K_v+G_v^\top\lambda^+\big)^\top(w-v^*)\ge0
\quad\text{for all }w\in\mathcal V.
\label{eq:impulse-vi}
\end{equation}
It becomes equality of the gradient to zero for an interior optimum. For payoff maximization, reverse the inequality, using the corresponding instantaneous payoff.

\begin{keyidea}{A finite reset is not a needle variation}
The vector $\lambda^+$ describes the first-order continuation value. It does not generally justify globally minimizing $K+(\lambda^+)^\top G$ over finite impulse changes. The exact dynamic-programming decision minimizes $K+V^+(\tau,G(x^-,v,\tau))$. A global impulse-Hamiltonian rule needs additional structure; the generic necessary condition is \eqref{eq:impulse-vi}.
\end{keyidea}
For a scalar recovery reset $x^+=(1-v)x^-$ and $K=cv^2/2$, \eqref{eq:costate-jump} becomes $\lambda^-=(1-v)\lambda^+$, and the interior magnitude equation is $cv-\lambda^+x^-=0$. The post-event costate depends on the entire resulting trajectory; this is a coupled necessary condition, not a closed-form global optimizer independent of the future.

\subsection{A freely chosen event time}
If an event time is a free interior decision, the reset and cost are smooth, and no event guard or timing constraint is active, its necessary condition is
\begin{equation}
\boxed{H^- -H^+ +K_t+(\lambda^+)^\top G_t=0.}
\label{eq:time-jump}
\end{equation}
The partial derivatives hold the pre-event state and magnitude fixed. To see the sign, differentiate the pre-event accumulated cost plus $K+V^+(\tau,G)$; use \eqref{eq:costate-jump} and $(V^+)_t=-H^+$. Hamiltonian continuity follows only when both $K$ and $G$ have no explicit time dependence. Guard-triggered switches, minimum spacing, endpoint events and active timing constraints require their corresponding multipliers or one-sided conditions.

For a hybrid game, every player's costate jumps at every event that changes the shared state. Each uses its own instantaneous payoff derivative. The controlling player also satisfies its impulse decision condition. Deriving only the intervening player's adjoint reset would omit the effect on the other players' future values.

\subsection{Impulse dynamic programming and the QVI}
For optional interventions in a minimization problem, define
\begin{equation}
(\mathcal MV)(t,x)=\inf_{v\in\mathcal V}\{K(x,v,t)+V(t,G(x,v,t))\}.
\end{equation}
Immediate intervention is an available choice, so $V\le\mathcal MV$. Waiting for a short interval is also available, giving
$V_t+\min_u(L+\nabla V^\top f)\ge0$. At least one choice is locally optimal. Thus the consistent minimization QVI is
\begin{equation}
\boxed{\min\left\{V_t+\min_u(L+\nabla V^\top f),\;\mathcal MV-V\right\}=0.}
\label{eq:qvi}
\end{equation}
In the continuation region the differential term is zero and intervention is more expensive. At an intervention point $V=\mathcal MV$. Equivalently, use a maximum with \emph{both} terms negated. Mixing a negated differential term with the unnegated obstacle inside a minimum changes the inequalities.

Assume an admissible class excluding infinitely many accumulating interventions and no intervention at $T$, so $V(T,x)=\Phi(x)$. A different terminal intervention convention needs a matching terminal value. For a fixed scheduled event, the boundary relation is instead
$V^-(\tau,x)=\inf_v[K+V^+(\tau,G)]$; optional-intervention QVI logic should not be imposed on a mandatory schedule without adjustment.

\subsection{What is optimized in a hybrid computation?}
A useful progression fixes event times and optimizes intensities, then considers admissible times for a fixed event count, and finally compares event counts if the application permits it. Each layer needs its own feasibility constraints and cost. Exhaustive or grid search is global only over the finite candidates actually examined. A demonstration that simulates specified impulses is a hybrid simulation, even when its continuous control is sophisticated.

The repository's \texttt{simulate\_continuous\_impulse} illustrates specified flow and reset decisions. The attributed research implementations explore richer impulse searches and games. Their settings should be read before adopting a numerical routine.

\subsection{Change five connected components together}
When replacing a model, update its state equation, state derivatives, objective, adjoint terminal/jump conditions and Hamiltonian optimizer together. The common numerical integrator and graph reader can usually be reused. For a two-state node model, state packing is part of this contract: for example $z=[x_1,\ldots,x_n,y_1,\ldots,y_n]$ must be used consistently by the RHS, Jacobian, costates and output labels.

For awareness-dependent susceptibility, an illustrative extension is
\begin{align}
\dot x_i&=\beta_i(1-y_i)(1-x_i)\sum_jA_{ij}x_j-(\delta_i+u_i)x_i,\nonumber\\
\dot y_i&=\eta_i(1-y_i)\sum_jC_{ij}y_j-\mu_i y_i+v_i(1-y_i).
\end{align}
Here $C$ is the awareness network, $y_i$ is awareness, and $v_i$ increases awareness rather than recovery. Cross-derivatives couple the infection and awareness costates. This is a model-adaptation illustration, not a claim that the default one-state script already solves the two-layer problem.

A delayed equation needs a history function and a delay-aware solver; ordinary \texttt{solve\_ivp} is an ODE solver, not a general DDE solver \cite{scipy}. A feedback decision problem with delay may also require a history-based state. Adding a lagged array lookup without specifying those objects does not complete the extension.

\section{Research examples: connect each method to its modeling purpose}
\subsection{APT evaluation, patching, repair and recovery}
Security evaluation begins by asking how a specified attack--defense mechanism evolves and how its equilibrium reflects security \cite{security2017}. A control problem adds an admissible intervention and a cost; a differential game further gives a strategic opponent its own decision and objective. The patch-injection and effective-repair papers illustrate this progression \cite{patch2018,repair2019}. Read the definition of a vulnerable, infected, insecure or repaired state before borrowing a transition: applying recovery control as $-u_i x_i$ and patching susceptible mass as $-u_i S_i$ are different mechanisms.

Backup and recovery introduce an additional operational possibility: information or functionality can be restored from a maintained backup \cite{backup2021}. The choice of state variables must represent the relevant recovery capability, and the objective must distinguish compromise loss from intervention and recovery costs. Simply renaming the recovery rate in an SIS equation does not reproduce a backup model. A useful exercise is to write the state and decision meanings from the paper, identify every controlled transition, and only then form its Hamiltonian.

Impulsive artificial defense studies interventions occurring as events rather than only as continuously applied rates \cite{impulse2023}. The outsourcing study introduces an impulsive differential-game setting with distinct decision makers \cite{outsource2024}. For either extension, first identify who chooses the continuous effort, event schedule and event intensity. The shared mathematical tools are the forward segments, reset map, costate jump and each player's own objective. The state definitions, event constraints and information structure remain those of the application.

\subsection{Conflicting opinions and rumor refutation}
The conflicting-opinion study formulates simultaneous benefit maximization for competing opinion processes \cite{opinions2020}. The rumor-refuting study links a propagation mechanism to the cost of refutation and strategic interaction \cite{rumor2021}. They motivate the use of two objectives rather than automatically setting $J_A=-J_D$. Expenditure by one party is not necessarily a benefit of equal size to the other.

To adapt the degree-game example, replace infection with explicitly defined opinion/rumor states and derive the transitions governing their interaction. If two exclusive states occupy the same population, their feasible region may be $x_k+y_k\leq1$ rather than two independent intervals. That change affects the RHS and adjoint coupling. The tutorial's one-state attacker--defender example therefore supplies a solution pattern, not the complete opinion or rumor model.

\subsection{Propaganda war: degree classes, two players and hybrid strategies}
Cheng et al. combine continuous and impulsive interventions in a dynamical propaganda-war game \cite{war2024}. The accompanying implementation organizes the propagation equations by degree classes. Begin with \path{demo_network.py}, which reads the networks and computes degree statistics, and continue to \path{propWar.py}. The forward routines \texttt{forwardRed}/\texttt{forwardBlue}, backward routines and separate payoff functions reveal how the two players share evolving propagation states while retaining their own objectives.

Trace one iteration as follows: choose both strategies, integrate the coupled state, integrate each player's adjoint under those strategies, update continuous/event decisions, and evaluate the corresponding payoff. Compare this with the simpler continuous degree-game loop in this note. Additional states and impulses require additional derivatives and jump conditions; the population weights and player-specific signs must remain aligned.

The accompanying \path{comparison.py} fixes one side and samples alternatives for the other. This gives empirical unilateral-deviation comparisons over the sampled strategies. An equilibrium claim over all admissible deviations additionally requires an appropriate theorem or a sufficiently justified best-response analysis. Its random alternatives should not be interpreted as an exhaustive search.

\subsection{Awareness and coupled malware--opinion dynamics}
The awareness-based propaganda paper develops impulse interventions for a spreading process influenced by awareness and network topology \cite{awareness2025}. Its \path{prop_network.py} constructs the network matrix; \path{prop_propaganda.py} supplies propagation, adjoints, policy search and payoff evaluation. The \path{prop_noAwareness.py} comparison isolates the role of the awareness mechanism. That ablation answers a model question, whereas random intervention comparisons answer a policy question.

The social-engineering malware paper couples malware and opinion/awareness dynamics on a multiplex network and uses separate patching and awareness-training impulse controls \cite{malware2025}. The code stores infection and awareness states separately: \texttt{forward\_C}, \texttt{forward\_O}, \texttt{backward\_dlamb} and \texttt{backward\_dmu} in \path{opinionMalware.py} are natural reading anchors. \path{network.py} builds the layers. A change to one layer can affect the other through cross-state derivatives, even when the networks have different edges.

When adapting the earlier two-state illustration, define both layers' node order, the coupling functions, each event's target and the instantaneous costs. At an event that changes only awareness, the infection state may be continuous while its subsequent derivative changes. This distinction explains why merely plotting a drop in infection at every awareness event would encode the wrong mechanism. Use the publication's actual equations for reproduction; the compact two-layer illustration above is a separately stated teaching model.

\subsection{Feedback control: update a model as new information arrives}
Jafar et al. connect reinforcement learning with MPC for malware control, using learning to estimate unknown model parameters within prescribed bounds \cite{feedback2024}. This provides a bridge between the three tutorials: the present note explains the dynamical control subproblem; Note 1 explains sequential learning and information patterns; Note 2 explains alternative inference and residual-learning constructions.

A generic receding-horizon implementation is
\begin{lstlisting}[caption={An estimation--control loop; the estimator is application-specific}]
for decision_time in decision_times:
    observation = observe_system()
    estimate = update_state_and_parameters(observation, history)
    plan = solve_finite_horizon_control(estimate, constraints)
    apply_first_interval(plan)
    history.append(observation)
\end{lstlisting}
This listing describes the interface, not the detailed algorithm of the cited paper. Replacing its estimator by a PINN or its controller by a learned policy is a new methodological choice. Evaluate estimation and decision quality separately so that a benefit from better information is not automatically attributed to a new optimizer or policy learner.

\section{Short exercises with worked answers}
\paragraph{Direction.} A directed dataset contains only \texttt{A,B,2}. With node order $(A,B)$, what is the incoming-influence matrix?\par
\emph{Answer:} $A=\left[\begin{smallmatrix}0&0\\2&0\end{smallmatrix}\right]$. Node B receives pressure $2x_A$.

\paragraph{Control weights.} Why does $P(k)$ appear in the denominator of \eqref{eq:degree-update}?\par
\emph{Answer:} The intervention cost is $P(k)r_ku_k^2/2$, whereas the costate term uses the unweighted state equation. Differentiating gives $P(k)r_ku_k-\lambda_kx_k$. Rescaling costates by class weights changes the adjoint equations as well as the update.

\paragraph{Finite impulse changes.} Let $G(v)=v$, $v\in[-1,1]$, $K(v)=1-v^2+v^4$, and terminal cost $\Phi(x)=x^2$. Does minimizing $K+\lambda^+G$ recover the actual optimum?\par
\emph{Answer:} The total cost is $1+v^4$, minimized at $v=0$, with $\lambda^+=\Phi'(0)=0$. The surrogate $K+\lambda^+G=1-v^2+v^4$ is minimized at $v=\pm1/\sqrt2$. The first-order condition at zero remains valid; the claimed global surrogate minimum does not.

\paragraph{Boundary optimality.} For $H(u)=u^2/2+2u$ and $0\le u\le1$, evaluate the optimum and projected residual.\par
\emph{Answer:} The optimum is $u=0$ although $H_u(0)=2$. With step size one, $u-\clip(u-H_u,0,1)=0$ at that optimum. The raw derivative penalty would incorrectly prefer moving away from the valid bound.

\section{Where to run extensions and numerical checks}
The ordinary entry point remains \texttt{python -m cybercontrol}. For the existing broader degree, node, game and hybrid examples, run
\begin{lstlisting}[language={}]
python -m cybercontrol study --output-dir results/extensions
\end{lstlisting}
For development, install \texttt{python -m pip install -e ".[dev]"} and run \texttt{pytest -q}. The public \texttt{check} command runs a small numerical check. Only \texttt{python -m cybercontrol docs} requires LaTeX/\texttt{latexmk}. Numerical correctness checks support the computation; scientific conclusions still depend on the model, data and comparison problem.
