# Reproducibility

## Environment

Python 3.10 or newer is required.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[graph,dev]"
```

`python-igraph` is optional for graph-backend comparisons. Install `.[dev]`
without the `graph` extra when a local igraph build is unavailable.

## One command pattern

The package-only smoke command works from an installed wheel. Run the remaining
commands from a source checkout:

```bash
python -m cybercontrol smoke
python -m cybercontrol medium --output-dir artifacts/medium
python -m cybercontrol figures
python -m cybercontrol docs
python -m cybercontrol all
```

`smoke` executes degree/node control, games and the continuous-impulsive model
on a small synthetic graph. `medium` uses a nontrivial horizon and compares
degree and sparse node FBSM on matched scale-free graphs at 100, 1,000 and
10,000 nodes. The larger million-node scalability profile remains an explicit
opt-in command:

```bash
python examples/foundations/code/scalability_analysis.py \
  --model-level compare \
  --sizes 100,1000,10000,100000,1000000 \
  --steps 12 --iterations 35 --tolerance 1e-3 --repeats 1 \
  --output-dir artifacts/scalability_100_to_1m
```

## Outputs

Generated CSVs, rerun figures and checkpoints belong under ignored
`artifacts/`. Curated README and LaTeX assets live under `docs/assets/` and are
regenerated by maintained scripts.

A run record should contain:

- command, Git SHA and UTC start time;
- Python, package and hardware information;
- graph/data source and adjacency convention;
- seed, resolved parameter arrays and matched-mean profile;
- horizon, grid, solver tolerance and iteration limit;
- convergence, invariant and finite-value diagnostics;
- method metrics and failed cases.

Use `cybercontrol.experiments` and `cybercontrol.io` at runner boundaries. The
library does not change the global RNG, thread count or device at import time.

## Validation gates

```bash
python -m compileall -q src examples tests scripts
python -m ruff check src tests examples scripts
python -m pytest -q
python -m cybercontrol smoke --output-dir artifacts/validation/smoke
python -m cybercontrol figures
python -m cybercontrol docs
```

Tests cover scalar/vector compatibility, mass and nonnegativity, dense/sparse
and NumPy/Torch parity, finite-difference Jacobians, deterministic profiles and
impulse semantics. Execution is not sufficient: inspect FBSM residuals,
objectives, baseline comparisons and state labels in the generated outputs.

## Diagrams and PDFs

`scripts/generate_diagrams.py` is the single maintained source for the shared
diagram set. It writes PDF, SVG and PNG assets plus
`docs/assets/diagram_manifest.csv`. Validate the manifest with:

```bash
python scripts/check_diagram_manifest.py
```

The main LaTeX source is `docs/source/network_control_foundations.tex`.
`python -m cybercontrol docs` builds it with `latexmk` and copies the current
PDF to `docs/network_control_foundations.pdf`.

## Literature evidence

`docs/literature/literature_decision_matrix.csv` records verified metadata,
rubric scores and claim boundaries. A `requested` row cannot support page-level
technical claims until a lawful PDF is reviewed and inventoried. PDFs and text
caches stay in ignored `literature_pdfs/` and `.literature_cache/`, not in Git.
